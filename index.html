🔑 API Anahtarı

Dersleri üretebilmek için bir Google AI Studio API anahtarına ihtiyacın var. Anahtarın yalnızca senin tarayıcında saklanır, hiçbir yere gönderilmez.

  1. Google AI Studio sayfasını aç.
  2. "Create API key" (Anahtar oluştur) düğmesine tıkla.
  3. Oluşan anahtarı kopyalayıp yukarıdaki kutuya yapıştır ve Kaydet'e bas.
